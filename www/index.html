配置 Strava 凭据

          
在 Strava My API Application 查看 Client ID / Client Secret，并添加回调地址 /oauth/callback。Refresh Token 通过 OAuth 授权自动获取。

          
          
          

          
          

            
          

          

          

            
            
          

          
「连接 Strava」会在独立窗口打开 Strava 授权页，授权后自动回填并保存 refresh_token。

        

      

      

        

          
API 使用指南

          
以下为管理面板 REST API 的 Markdown 文档，可直接复制给 agent 使用。

          

            
            
            
          

          

          

        

      

      

        

          
模型设置 (LLM)

          
接入 OpenAI 兼容 API(本地网关如 Ollama / LM Studio / vLLM,或云端),用于「训练建议」页签的 AI 教练。密钥仅存本地 strava.conf(权限 600)。

          
          
          

          

          

            
            
          

          
本地 API 网关示例:Ollama 填 http://127.0.0.1:11434/v1(Key 任意);LM Studio 填 http://127.0.0.1:1234/v1;也支持任何 OpenAI 兼容网关(One-API / LiteLLM)。

        

        

          
模型库

          
点选卡片设为默认模型(训练建议页从库中选择,不再全量拉取网关列表);悬停卡片右上角可移除。

          

          

          

          

            
            
            
          

          
          

            
            
          

        

      

      

        

          
运动员偏好

          

            
运动方式

            
勾选你实际进行的运动方式。AI 教练只会推荐所选运动内的训练，训练数据摘要也按此过滤；训练建议页顶部的「运动方式」与此同步。

            

          

          

            
运动时间

            
你通常在什么时间段训练？教练排课会优先安排在这些窗口内。

            

          

          

            
            
          

        

      

      

        

          
数据管理

          
骑行数据缓存到本地 SQLite。可手动同步 Strava→SQLite，或导出全量数据给 agent 使用。

          

            
            
            
            
          

          

          

            

              自动同步
              
              
            

            
开启后服务端按周期自动执行增量同步(仅拉取新活动);手动同步不受影响。

          

          

            
Intervals.icu 真实功率数据源

            
接入后「功率曲线」将自动展示 Intervals.icu 的秒级真实最佳功率曲线与 eFTP。

            

              
              
              
            

            
          

        

      

      

        

          
会话管理

          
为每个会话重命名、选择辅助模型(留空用默认配置)。训练建议页的「会话」下拉同步此处。
